# PI0.5 Phase-Aware Trajectory Analysis

## Method

This analysis uses saved `state_trajectory.npz` and `actions.npz` to summarize physical trajectory phases, rather than probing hidden states or interpreting a single flow vector.

Phase proxies:

- approach: early and pre-close target-distance reduction
- close/grasp timing: first gripper-close step and target distance at close
- lift: target max lift and first target-lift step
- recovery: success despite non-target first move/lift or bad early alignment

## Main Readout

The phase readout should be used to decide what causal interventions need to change.

Initial interpretation rules:

- If success and failure have similar min target distance but different lift, the failure is likely grasp/lift rather than approach.
- If failures close far from the target or close before nearest approach, the failure is likely gripper timing / commitment.
- If all-failure tasks approach the target but never lift, object selection is not the main bottleneck.
- If successful rollouts recover from non-target first movement, intervention readouts need recovery-phase metrics, not only first action direction.
